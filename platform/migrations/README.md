# 数据库迁移

- 开发启动仍由 `modules/system.AutoMigrate` 创建基础表。
- 已发布环境按编号执行本目录 SQL，不得只依赖 GORM Tag 改变存量结构。
- `0002_users_auth_version.sql` 为存量用户补齐授权版本；执行后旧 JWT 需要重新登录。
- `0003_role_management.sql` 只为角色补充描述与内置保护字段；初始管理员、内置角色和权限由安装向导创建。
- `0004_tenant_setting_values.sql` 创建租户设置覆盖值表；分类/字段 Schema 由代码注册，不在库中存 Definition。
- `0033_user_setting_values.sql` 创建按租户与当前用户隔离的 user-scope 设置覆盖值表。
- `0034_trusted_runtime_context.sql` 为 Agent Run 固定服务端时间快照，并为 Context Snapshot 增加脱敏 Runtime Context refs。
- `0035_memory_hybrid_recall.sql` 增加记忆召回硬过滤索引与 Snapshot provenance refs。
- `0036_agent_slots.sql` 创建租户 Agent Slot 绑定与用户偏好表；Slot Definition 和系统默认仍由代码注册，迁移不写业务数据。
- `0038_structured_output_strategy.sql` 为模型调用账本增加结构化输出安全策略名称，不保存 Schema、Prompt 或响应正文。
- `0005_attachments.sql` 创建 `attachments` / `attachment_links` 与状态 CHECK；附件策略与 AccessPolicy 由代码注册。
- `0011_audit_log_indexes.sql` 为租户审计时间线、Action 与资源筛选增加复合索引。
- `0012_authentication_sessions.sql` 创建统一认证身份、challenge 与轮换会话表；旧 JWT 缺少 `sid`，升级后需重新登录。
- `0013_ai_model_governance.sql` 创建租户隔离的 Provider、Model Deployment 与 Alias 表，只包含结构、约束和引用完整性，不写模型业务数据。
- `0014_ai_provider_encrypted_credentials.sql` 将 Provider 凭证改为数据库密文；旧引用不兼容，升级时停用并要求管理员重新录入。
- `0015_ai_model_invocations.sql` 创建最小模型调用事实台账，只保存安全元数据、状态、时延和供应商明确报告的 Usage。
- `0016_ai_tool_runtime.sql` 创建工具目录投影、ToolScope、单次确认与安全调用事实台账，不写初始化业务数据。
- `0019_ai_conversations.sql` 创建租户会话、不可变追加消息与 ContextSnapshot，只保存会话事实，不执行模型或压缩。
- `0020_ai_context_compaction.sql` 扩展版本化压缩 Snapshot 的策略、Schema、Prompt、摘要模型、深度与质量字段。
- `0021_ai_agent_runtime.sql` 创建 Agent Run、追加式 Step、可续传事件和 lease/预算状态，不写业务初始化数据。
- `0022_drop_agent_user_instructions.sql` 删除 `ai_agent_versions.user_instructions`；Agent 配置只保留租户指令，用户偏好改由 Workspace/记忆承担。
- `0023_builder_preview.sql` 为 Agent Version 增加 `kind`/`content_hash`（preview 不晋升 current），为 Conversation 增加 `purpose`（builder_preview 与 Workspace 隔离）。
- `0025_ai_knowledge_foundation.sql` 创建知识库、文档、索引版本、Chunk 元数据与 Agent 候选绑定，只保存可信来源和版本事实。
- `0026_ai_knowledge_ingestion.sql` 启用 pgvector，增加摄取触发 revision 与隔离的 Chunk 正文/向量载荷表；载荷不得进入 API、日志、审计或 Outbox。
- `0027_ai_knowledge_retrieval.sql` 为 Chunk 载荷增加生成式 FTS 列与 GIN 索引，混合排序仍只读取当前原子发布版本。
- `0031_memory_candidate_extraction.sql` 创建每 Run 唯一的记忆评估水位，并为 candidate 增加冻结 Policy、Invocation、版本和参数哈希追溯字段。
- `0032_memory_governance_projections.sql` 创建确定性治理决策、追加式关系与串行整理批次，并扩展可重建的按日归档和当前画像 provenance。
