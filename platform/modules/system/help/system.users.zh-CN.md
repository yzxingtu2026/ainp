# 用户管理

## 页面用途
管理当前租户的用户账号、基础资料与账号状态。

## 新增用户

### 前置条件
当前账号具有用户管理权限，并已准备好用户名和用户基本信息。

### 操作步骤
1. 进入用户管理页面，选择新增用户。
2. 填写必填的账号与基础资料。
3. 核对信息后提交保存。

## 停用用户
1. 在用户列表中找到目标用户。
2. 打开状态操作并选择停用。
3. 核对影响范围后确认。

> 帮助内容仅提供操作说明，不会代替用户点击、填写或提交。
