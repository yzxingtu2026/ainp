# 后端多语言 i18n

- 翻译文件：`platform/i18n/*.yaml`（文件名即语言标识，如 `zh-CN.yaml`、`en.yaml`），运行时加载，**禁止** `go:embed` 打进二进制。
- 新增/修改翻译后调 `POST /api/v1/system/i18n/reload` 热重载；启动时由 `app.Run()` 自动 `i18n.LoadDir()`。
- key 格式：`domain.reason` 小写点分（如 `auth.invalid_credentials`）；新增 key 必须在**所有**语言文件中补齐。
- 业务 handler 读语言：`lang := i18n.FromCtx(ctx)`；翻译：`i18n.T(lang, key)`。
- 错误响应：`errs.NewKey(code, key, fallback)` 或 `errs.ValidationKey(key, fallback, fields...)`；`errs.New` 自动按 `codeDefaultKey` 映射。
- Capability / Action / Menu 注册时填 `NameKey` / `DescriptionKey` / `TitleKey`，`Name` / `Description` / `Title` 仅作兜底。
- 前端请求层已注入 `Accept-Language` 头（源自 `localStorage.lang`）；后端中间件 `AcceptLanguage()` 解析后写入 `AuthContext.Language`。
- 新增语言：创建 `platform/i18n/{lang}.yaml` → 填齐所有 key → 调 reload API → 完成。无需改 Go 代码。

详规：`docs/development/api-response.md`
